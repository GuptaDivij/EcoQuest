To run the app:
1. Clone the repository into a folder of your choosing with the following command: "git clone https://github.com/GuptaDivij/EcoQuest.git"
2. CD into the "eco-quest" directory where the package.json file is located.
3. In this directory "npm install --save-dev concurrently" to install the main dependencies.
4. Finally, in the same directory, do "npm start" to run the app.
5. If the app does not run, install dependencies according to whatever error messages that pop up, and do "npm start" again.
